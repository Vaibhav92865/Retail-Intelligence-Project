# 🛍️ Retail Intelligence Project

## Project Overview
Retail Intelligence is a Data Science and Business Intelligence project that analyzes online retail sales data to understand sales performance, customer behavior, and customer segmentation.

## Objectives
- Analyze retail sales performance.
- Identify top-performing products.
- Understand monthly revenue trends.
- Segment customers using RFM Analysis and K-Means Clustering.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQL / SQLite
- Power BI
- Jupyter Notebook

## Key Analysis
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Revenue Analysis
- RFM Analysis
- Customer Segmentation
- K-Means Clustering
- Interactive Dashboard
